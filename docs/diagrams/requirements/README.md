## 编辑与插入 Word

1. 打开 `.drawio` 文件，通过下方页面标签选择对应图号，修改文字或拖动节点、连接线。
2. 使用微软雅黑字体。修改后检查条件标签、连线与节点的距离，保留起止节点及汇合节点；图 3.3.10 和图 3.3.11 通过连接点 A 衔接。
3. 在编辑器中导出 SVG 或 PNG。PNG 导出时保留白色背景，宽度至少为 1831 像素。
4. 插入 Word 后设置宽度为 15.5 厘米并锁定纵横比，使用嵌入型图片，题注放在下方并与图保持同页。当前 PNG 为 300 dpi，图内最小字号在此尺寸下约为 10.5 磅；较小的插入尺寸会相应缩小文字。

SVG 保留矢量图形及可选择的文字，使用支持中文的字体打开即可。PNG 已将中文文字渲染为图像，适合直接插入课程文档和打印。

## 流程说明

购物车查看路径保持只读；修改、删除和清空路径使已有报价失效。创建订单前校验确认标识、报价一致性和有效期，并进行一次性占用。订单创建分别处理成功、明确失败和结果未知，失败与未知均不自动重试，结果未知保留为待核对状态。

公开交付仅包含本目录的图源、图片及说明。修订后的完整 Word、教师模板和往届参考材料在本地保留。
