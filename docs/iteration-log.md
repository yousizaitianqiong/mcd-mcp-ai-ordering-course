## 1. 状态定义

| 状态 | 含义 |
| --- | --- |
| 计划中 | 已确定目标，但尚未开始或没有交付证据 |
| 进行中 | 已开始，仍有未完成项 |
| 已验证 | 目标范围已完成，并有命令、审查、截图或录屏证据 |
| 阻塞 | 因外部条件或明确缺口无法继续，已记录解除条件 |

## 4. 证据和隐私规则

- 命令输出只保留必要的状态、错误码和测试数量。
- 页面证据遮盖真实地址、手机号、Token、模型 Key、Authorization Header 和完整支付链接。
- 真实订单只记录脱敏标识、时间和状态，不记录支付密码或银行卡信息。
- 如果出现网络错误、401、429、超时或未知订单状态，保留失败证据并停止真实写操作，不用 Mock 结果覆盖。
